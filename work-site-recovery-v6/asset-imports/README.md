# 3D cinematic image import drop-zone

Place `MTS_Arena_3D_Activity_Artwork.zip` **in this folder** on branch `develop/v6-github-arena`.
The GitHub Action `V6 install approved cinematic art archive` verifies exactly ten WebP images, imports them into public/activity-art, updates ActivityArt to use `.webp`, runs tests and builds, and commits the change without touching `main` or publishing the site.

Do not put images or ZIP files containing customer, employee, or other personal information here. This folder is intended only for public training-activity illustrations.
